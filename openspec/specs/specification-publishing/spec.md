# specification-publishing Specification

## Purpose
组装并版本化需求说明书，提供 HTML 在线预览、Word 导出以及需求清单的浏览与导出。适用于评审稿、开发交底与验收对照所需的文档交付。

## Requirements

### Requirement: 说明书组装
系统 SHALL 使用 prd-assemble 说明书组装技能契约（与迭代说明书同一解析链）将项目概述、项目需求说明、功能说明、应用集成说明与审批意见五章正文及附录 A–Q 组装为需求分析说明书，HTML 外壳遵循技能模板占位符契约。

#### Scenario: 生成说明书
- **WHEN** 需求分析完成且原型已确认
- **THEN** 系统解析唯一可用文档技能（默认内置 prd-assemble）并生成说明书
- **AND** 标注版本号、生成时间、技能 slug 与技能版本
- **AND** 每个章节标注内容来源与更新时间

#### Scenario: 章节缺内容
- **WHEN** 任一必填章节为空
- **THEN** 系统拒绝生成正式版本
- **AND** 输出缺项清单

#### Scenario: 技能不可用
- **WHEN** 无可用文档技能（未绑定且内置技能停用）
- **THEN** 系统拒绝生成并返回技能不可用原因与候选列表
- **AND** 不使用硬编码模板绕过技能

### Requirement: HTML 在线预览
系统 SHALL 提供自包含 HTML 格式的说明书在线预览，支持目录跳转、图表与原型展示。

#### Scenario: 预览打开
- **WHEN** 用户点击在线预览
- **THEN** 系统在浏览器中打开说明书
- **AND** 侧边目录可跳转到任意章节

#### Scenario: 图片与图表加载
- **WHEN** 说明书包含流程图、架构图或原型截图
- **THEN** 预览页内联显示且不依赖外部图床
- **AND** 加载失败时显示占位与原始说明

### Requirement: Word 导出
系统 SHALL 在服务端生成 Word 格式的说明书导出文件，保持章节结构、图表与表格。

#### Scenario: 导出成功
- **WHEN** 用户请求导出 Word
- **THEN** 系统生成文件并提供下载地址
- **AND** 文件名包含需求编号与版本号

#### Scenario: 导出内容校验
- **WHEN** 导出任务完成
- **THEN** 系统校验章节数量、图片数量与表格数量
- **AND** 校验不通过时标记导出失败并保留原因

### Requirement: 需求清单浏览
系统 SHALL 提供需求清单界面，支持按项目、迭代、阶段状态、涉及应用与负责人浏览与筛选。

#### Scenario: 浏览清单
- **WHEN** 用户打开需求清单
- **THEN** 系统分页展示已分配编号且未丢弃的需求
- **AND** 每行显示编号、标题、阶段状态、迭代与负责人

#### Scenario: 查看需求详情
- **WHEN** 用户点击某条需求的编号或标题
- **THEN** 系统打开该需求的需求详情页
- **AND** 保留清单的筛选条件以便返回

#### Scenario: 打开工作台
- **WHEN** 用户点击需求清单中的「打开」
- **THEN** 系统按当前状态进入对应环节的需求分析工作台
- **AND** 不改变需求详情入口

#### Scenario: 按阶段筛选
- **WHEN** 用户按状态筛选需求清单
- **THEN** 系统按 0 至 13 阶段顺序展示全部可选阶段及非阶段状态
- **AND** 不提供已废弃的旧状态名称

### Requirement: 需求清单导出
系统 SHALL 支持将当前筛选结果导出为 Excel 与 CSV，并记录导出人与导出时间。

#### Scenario: 导出筛选结果
- **WHEN** 用户导出当前筛选后的清单
- **THEN** 系统按列定义生成文件，默认格式为 Excel（临时口径，见 design.md Q-002）
- **AND** 导出范围与界面筛选条件一致

#### Scenario: 导出字段受权限限制
- **WHEN** 用户无某些字段的查看权限
- **THEN** 导出文件不包含这些字段
- **AND** 在导出记录中注明字段裁剪

### Requirement: 说明书版本管理
系统 SHALL 为单需求说明书与迭代说明书分别维护版本序列，记录每版变更摘要、触发来源与审批状态，并保留需求版本与迭代版本之间的引用关系。

#### Scenario: 生成新版本
- **WHEN** 分析、原型或评审导致内容变化
- **THEN** 系统生成新版本并关联触发来源
- **AND** 旧版本转为只读

#### Scenario: 版本发布标记
- **WHEN** 某版本通过评审
- **THEN** 系统将其标记为已发布版本
- **AND** 后续导出默认使用该版本

#### Scenario: 迭代版本引用需求版本
- **WHEN** 迭代说明书生成成功
- **THEN** 系统记录其引用的每条需求说明书版本
- **AND** 可按需求版本追溯其参与过的迭代说明书

#### Scenario: 需求版本更新后的迭代版本
- **WHEN** 已关联需求的说明书发布新版本
- **THEN** 引用旧版本的迭代说明书标记为待更新
- **AND** 旧迭代版本保持可查

### Requirement: 迭代说明书组装
系统 SHALL 按迭代聚合全部纳入需求的分析内容，使用项目登记且适用于「说明书」环节的技能，组装为迭代级需求分析说明书，并在生成时同时固化 HTML 与 Word 两份产物。

#### Scenario: 生成草稿版
- **WHEN** 产品经理在迭代详情发起生成说明书
- **THEN** 系统纳入迭代内状态不为需求调研中、已丢弃的需求
- **AND** 组装迭代总览、需求分篇与附录
- **AND** 缺失内容在对应章节标注待补

#### Scenario: 生成正式版
- **WHEN** 全部纳入需求均具备分析版本、一致性核查通过、原型已确认且说明书已发布
- **THEN** 系统生成正式版本并标注版本号与生成时间
- **AND** 每个章节标注来源需求编号、更新时间与阶段状态

#### Scenario: 正式版缺项
- **WHEN** 任一纳入需求缺少分析版本、未通过一致性核查、原型未确认或说明书未发布
- **THEN** 系统拒绝生成正式版
- **AND** 输出缺项清单并允许生成草稿版

#### Scenario: 需求内容更新
- **WHEN** 迭代内某条需求产生新的分析或说明书版本
- **THEN** 既有迭代说明书标记为待更新
- **AND** 不自动合并，须重新生成

#### Scenario: 迭代为空
- **WHEN** 迭代内没有可纳入的需求
- **THEN** 系统拒绝生成说明书
- **AND** 提示先完成需求排期与确认

#### Scenario: 使用技能生成
- **WHEN** 用户确认生成说明书并选择了一个可用文档技能
- **THEN** 系统按该技能的 HTML 模板与校验规则组装文档
- **AND** 版本记录技能绑定、技能 slug、技能版本与模板摘要
- **AND** 文档页脚与附录标注生成技能与版本

#### Scenario: 阶段范围
- **WHEN** 迭代内同时存在需求调研中、已丢弃与已排期需求
- **THEN** 系统只纳入已排期需求
- **AND** 在生成报告中列出未纳入需求与原因

### Requirement: 迭代说明书在线预览
系统 SHALL 把迭代说明书以单文件自包含 HTML 的形式提供，并在新标签页直接打开该 HTML 文件，而不是在应用内嵌 iframe 预览。

#### Scenario: 打开预览
- **WHEN** 用户点击迭代说明书的预览入口
- **THEN** 浏览器在新标签页打开该版本的 HTML
- **AND** 左侧目录可跳转到迭代总览、任一需求章节与附录

#### Scenario: 预览响应
- **WHEN** 浏览器请求预览地址
- **THEN** 响应以 `Content-Disposition: inline` 返回 HTML
- **AND** 禁止缓存并声明 `nosniff`
- **AND** 不允许被应用页面或第三方页面以 iframe 嵌入

#### Scenario: 自包含资源
- **WHEN** 说明书包含流程图、架构图或原型截图
- **THEN** 图片以 base64 内嵌且不引用外部图床、CDN 或外部样式
- **AND** 断开网络后仍可完整阅读

#### Scenario: 锚点直达
- **WHEN** 用户通过链接打开某条需求章节
- **THEN** 页面定位到该需求的稳定锚点
- **AND** 目录同步高亮当前位置

#### Scenario: 缺图占位
- **WHEN** 某图表或原型截图缺失
- **THEN** 预览显示占位与原始说明
- **AND** 在附录的一致性核查中列出

#### Scenario: 预览权限
- **WHEN** 访客请求草稿版本的预览地址
- **THEN** 系统拒绝访问
- **AND** 已发布版本按既有权限规则可查看

#### Scenario: 脚本与外部请求被阻断
- **WHEN** 预览 HTML 被浏览器加载
- **THEN** 响应安全策略禁止脚本执行与外部资源请求
- **AND** 只允许内联样式与 data 图片

### Requirement: 迭代说明书导出
系统 SHALL 支持将迭代说明书导出为 Word 与 PDF；Word 优先返回生成时固化的文件，导出内容与在线预览保持一致。

#### Scenario: 导出 Word
- **WHEN** 用户请求导出 Word
- **THEN** 系统返回该版本生成时固化的 Word 文件
- **AND** 文件名包含迭代名称与版本号
- **AND** 章节、图片与需求条目数量与 HTML 一致

#### Scenario: 固化文件缺失
- **WHEN** 新版本记录的 Word 文件不存在或与记录的大小、摘要不符
- **THEN** 系统返回产物缺失或校验失败错误
- **AND** 不静默重新生成或返回其它版本的文件

#### Scenario: 历史版本导出
- **WHEN** 历史版本没有固化的 Word 文件
- **THEN** 系统按内置技能与标准结构即时生成 Word
- **AND** 不回写历史版本记录
- **AND** 在导出审计中标注为回退生成

#### Scenario: 导出 PDF
- **WHEN** 用户请求导出 PDF
- **THEN** 系统通过无头浏览器打印同一份 HTML 生成 PDF
- **AND** 内联图片、目录与章节结构与 HTML 一致

#### Scenario: PDF 引擎不可用
- **WHEN** 运行环境缺少可用的无头浏览器
- **THEN** 系统返回导出失败与原因
- **AND** 不生成降级或损坏的 PDF 文件

#### Scenario: 导出一致性校验失败
- **WHEN** 导出文件的章节数、图片数或需求条目数与 HTML 不一致
- **THEN** 系统标记导出失败并保留差异明细
- **AND** 不提供该文件下载

#### Scenario: 导出留痕
- **WHEN** 导出成功
- **THEN** 系统记录导出人、格式、迭代、版本与时间
- **AND** 记录关联的说明书版本、技能 slug 与技能版本

### Requirement: 需求说明书技能化生成与追溯
系统 SHALL 在生成需求说明书时确定唯一一个可用文档技能（显式选择 → 上一版本技能 → 内置 prd-assemble → 项目内唯一可用文档技能），并把技能绑定、技能 slug、技能版本与模板摘要写入版本记录；历史无技能字段的版本按旧渲染口径回放并标注，不回写。

#### Scenario: 显式选择技能
- **WHEN** 生成请求携带技能绑定标识
- **THEN** 系统校验该绑定属于当前项目、已启用且适用环节包含「说明书」
- **AND** 校验通过后按该技能模板与校验规则生成

#### Scenario: 未显式选择技能
- **WHEN** 生成请求未携带技能绑定标识
- **THEN** 系统依次尝试上一版本技能、内置 prd-assemble、项目内唯一可用文档技能
- **AND** 仍无法确定唯一技能时拒绝生成并返回候选列表

#### Scenario: 生成留痕
- **WHEN** 需求说明书生成成功
- **THEN** 版本记录包含技能绑定、技能 slug、技能版本与模板摘要
- **AND** 写入技能执行记录（阶段「说明书」、触发方式「文档生成」、令牌与成本为 0）与审计

#### Scenario: 历史版本回放
- **WHEN** 用户预览或导出无技能字段的历史版本
- **THEN** 系统按旧九段确定性渲染器回放
- **AND** 条目与页脚标注「旧版渲染」

### Requirement: 需求说明书章节契约
系统 SHALL 按 prd-assemble 约定的章节结构输出需求说明书：正文五章（1 项目概述、2 项目需求说明、3 功能说明、4 应用集成说明、5 审批意见）与附录 A–Q；需求编号不得出现在正文叙述与标题中，只允许出现在追踪表「编号」列与附录索引。

#### Scenario: 五章齐全
- **WHEN** 说明书生成成功
- **THEN** 正文按五章组织，功能说明按应用分组并内嵌对应流程图产物
- **AND** 项目概述引用项目档案的范围与目标，项目需求说明引用澄清结论快照

#### Scenario: 附录生成
- **WHEN** 正文组装完成
- **THEN** 系统按产物与过程数据生成附录 A–Q：G 图表索引列出流程图版本与技能元数据、H 原型索引列出原型页面、K 需求澄清单引用澄清结论、N 项目画像与范围引用项目档案、O 一致性核对引用分析核查结果、Q 交互确认记录引用提案与确认留痕
- **AND** 无内容的可选附录（I、P）整章省略

#### Scenario: 编号进入正文
- **WHEN** 渲染结果在正文叙述或标题中出现需求编号
- **THEN** 系统拒绝生成并定位出现位置
- **AND** 编号仅允许出现在追踪表与附录索引

#### Scenario: Word 导出
- **WHEN** 用户导出 Word
- **THEN** 系统按标准章节结构生成，章节数与 HTML 一致
- **AND** 导出审计记录技能 slug 与技能版本
