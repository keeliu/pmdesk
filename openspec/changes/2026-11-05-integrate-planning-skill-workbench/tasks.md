# 实施任务

## 规格覆盖对照

| 能力 | 任务分组 | 覆盖场景 |
| --- | --- | --- |
| project-iteration-management | 1 | 导航、入口、高亮、返回、历史地址、能力保持 |
| ai-orchestration | 2、3、4 | 项目注册表、导入校验、引用、环节配置、会话使用 |
| access-control | 3 | 权限拒绝、来源成员、引用与变更留痕 |
| requirement-analysis | 6 | 截断、详情、来源回退、环节切换、空态 |

## 0. 确认与准备

- [ ] 0.1 用户确认本变更的提案、设计与增量规格，冻结范围
- [ ] 0.2 记录当前测试、类型检查与构建基线

## 1. 规划入口整合

- [ ] 1.1 移除顶部导航的独立「规划」页签，保留规划页路由与深链
- [ ] 1.2 打开规划页时顶部「迭代」保持高亮，并提供返回迭代列表入口
- [ ] 1.3 迭代列表、迭代详情与空态中的入口文案统一改为「规划」
- [ ] 1.4 规划页标题与辅助文案统一使用「规划」，入口不再出现「去排期」
- [ ] 1.5 浏览器验证：无独立页签、两个入口、高亮、返回、历史地址、拖拽与容量校验不变

## 2. 项目技能数据与迁移

- [ ] 2.1 新增项目技能绑定表，包含技能包、来源类型、来源项目、适用环节与启用状态
- [ ] 2.2 启动迁移幂等补齐存量项目的内置技能绑定，新项目创建时自动绑定
- [ ] 2.3 技能查询改为项目维度，有效启用状态按技能包与绑定取与
- [ ] 2.4 场景测试：项目隔离、内置技能默认可用、重复绑定唯一约束

## 3. 技能导入与引用

- [ ] 3.1 实现技能清单解析与校验：必填字段、环节取值、路径安全、体积与文件数、类型白名单
- [ ] 3.2 实现压缩包与文件夹两种导入方式，失败原子回滚，重复 slug 返回冲突
- [ ] 3.3 实现引用候选接口与服务端成员校验，引用绑定记录来源项目与技能包
- [ ] 3.4 实现来源停用或移除后的「来源不可用」状态与执行错误
- [ ] 3.5 实现适用环节配置、启停与移除；内置技能禁止移除
- [ ] 3.6 执行接口改为按项目技能绑定执行，校验当前环节与有效启用状态
- [ ] 3.7 写入导入、引用、配置、启停、移除审计，记录前后值与来源
- [ ] 3.8 场景测试：合法导入、非法包、重复、跨项目权限、来源停用、环节不匹配、审计

## 4. 技能会话执行

- [ ] 4.1 会话请求携带当前环节，服务端计算该环节可用技能集合
- [ ] 4.2 系统提示只暴露当前环节可用技能，未配置环节的技能由模型判断并要求说明理由
- [ ] 4.3 模型使用技能时校验范围并写入调用记录，失败时明示未执行原因
- [ ] 4.4 技能输出不直接写库，任何写回仍经提案确认闸门
- [ ] 4.5 场景测试：自动使用、越界拒绝、模型不可用降级

## 5. 技能管理界面

- [ ] 5.1 设置页页签与卡片文案改为「技能管理」「项目技能」，说明按项目生效
- [ ] 5.2 实现「添加技能」弹窗：上传技能包与引用其它项目两种模式
- [ ] 5.3 实现适用环节多选，未选择时展示由大模型识别的提示
- [ ] 5.4 列表展示来源、适用环节与启停状态，提供配置与移除；内置技能只允许配置与停用
- [ ] 5.5 非管理角色只读展示，导入与引用错误在弹窗内逐条提示
- [ ] 5.6 浏览器验证两种添加方式、环节配置、启停、移除与来源标签

## 6. 需求描述固定区

- [ ] 6.1 实现描述来源解析：确认快照、原文摘要、完整原文、澄清结论拼接与空态
- [ ] 6.2 实现预览标题与描述区的吸顶容器，正文最多三行并检测溢出
- [ ] 6.3 实现「查看详情」只读弹窗，展示完整描述与可用元信息
- [ ] 6.4 仅在分析、原型、评审与变更环节展示，切换环节保持固定
- [ ] 6.5 浏览器验证长描述、短描述、缺失描述、滚动固定、弹窗与窄屏布局

## 7. 回归与交付

- [ ] 7.1 执行场景测试、类型检查与生产构建，全部通过
- [ ] 7.2 全链路浏览器走查：规划入口、技能添加与引用、描述固定区、既有主流程
- [ ] 7.3 对照规格逐条核查并勾选任务，确认无遗漏后归档变更
