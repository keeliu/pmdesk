# specification-publishing Delta

## MODIFIED Requirements

### Requirement: 说明书组装
系统 SHALL 使用 prd-assemble 说明书组装技能契约（与迭代说明书同一解析链）将项目概述、项目需求说明、功能说明、应用集成说明与审批意见五章正文及附录 A–Q 组装为需求分析说明书，HTML 外壳遵循技能模板占位符契约。

#### Scenario: 生成说明书
- **WHEN** 需求分析完成且原型已确认
- **THEN** 系统解析唯一可用文档技能（默认内置 prd-assemble）并生成说明书
- **AND** 标注版本号、生成时间、技能 slug 与技能版本
- **AND** 每个章节标注内容来源与更新时间

#### Scenario: 章节缺内容
- **WHEN** 任一必填章节为空
- **THEN** 系统拒绝生成正式版本
- **AND** 输出缺项清单

#### Scenario: 技能不可用
- **WHEN** 无可用文档技能（未绑定且内置技能停用）
- **THEN** 系统拒绝生成并返回技能不可用原因与候选列表
- **AND** 不使用硬编码模板绕过技能

## ADDED Requirements

### Requirement: 需求说明书技能化生成与追溯
系统 SHALL 在生成需求说明书时确定唯一一个可用文档技能（显式选择 → 上一版本技能 → 内置 prd-assemble → 项目内唯一可用文档技能），并把技能绑定、技能 slug、技能版本与模板摘要写入版本记录；历史无技能字段的版本按旧渲染口径回放并标注，不回写。

#### Scenario: 显式选择技能
- **WHEN** 生成请求携带技能绑定标识
- **THEN** 系统校验该绑定属于当前项目、已启用且适用环节包含「说明书」
- **AND** 校验通过后按该技能模板与校验规则生成

#### Scenario: 未显式选择技能
- **WHEN** 生成请求未携带技能绑定标识
- **THEN** 系统依次尝试上一版本技能、内置 prd-assemble、项目内唯一可用文档技能
- **AND** 仍无法确定唯一技能时拒绝生成并返回候选列表

#### Scenario: 生成留痕
- **WHEN** 需求说明书生成成功
- **THEN** 版本记录包含技能绑定、技能 slug、技能版本与模板摘要
- **AND** 写入技能执行记录（阶段「说明书」、触发方式「文档生成」、令牌与成本为 0）与审计

#### Scenario: 历史版本回放
- **WHEN** 用户预览或导出无技能字段的历史版本
- **THEN** 系统按旧九段确定性渲染器回放
- **AND** 条目与页脚标注「旧版渲染」

### Requirement: 需求说明书章节契约
系统 SHALL 按 prd-assemble 约定的章节结构输出需求说明书：正文五章（1 项目概述、2 项目需求说明、3 功能说明、4 应用集成说明、5 审批意见）与附录 A–Q；需求编号不得出现在正文叙述与标题中，只允许出现在追踪表「编号」列与附录索引。

#### Scenario: 五章齐全
- **WHEN** 说明书生成成功
- **THEN** 正文按五章组织，功能说明按应用分组并内嵌对应流程图产物
- **AND** 项目概述引用项目档案的范围与目标，项目需求说明引用澄清结论快照

#### Scenario: 附录生成
- **WHEN** 正文组装完成
- **THEN** 系统按产物与过程数据生成附录 A–Q：G 图表索引列出流程图版本与技能元数据、H 原型索引列出原型页面、K 需求澄清单引用澄清结论、N 项目画像与范围引用项目档案、O 一致性核对引用分析核查结果、Q 交互确认记录引用提案与确认留痕
- **AND** 无内容的可选附录（I、P）整章省略

#### Scenario: 编号进入正文
- **WHEN** 渲染结果在正文叙述或标题中出现需求编号
- **THEN** 系统拒绝生成并定位出现位置
- **AND** 编号仅允许出现在追踪表与附录索引

#### Scenario: Word 导出
- **WHEN** 用户导出 Word
- **THEN** 系统按标准章节结构生成，章节数与 HTML 一致
- **AND** 导出审计记录技能 slug 与技能版本
