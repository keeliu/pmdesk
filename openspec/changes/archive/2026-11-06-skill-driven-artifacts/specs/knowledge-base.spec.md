# knowledge-base Delta

## MODIFIED Requirements

### Requirement: 产物登记范围
系统 SHALL 按以下范围登记产物：每个生成成功的流程图产物（分析版本提交时按图表技能解析链生成并持久化）登记为流程图；每个原型版本登记为原型；每个需求说明书版本与迭代说明书版本登记为需求说明书。

#### Scenario: 流程图登记
- **WHEN** 分析版本的功能流程步骤生成流程图成功
- **THEN** 该产物出现在流程图分类
- **AND** 流程图标题包含需求标识与分析版本
- **AND** 条目展示渲染器（archify 交互图 / builtin 降级清单）与技能版本

#### Scenario: 流程图生成失败
- **WHEN** 流程图生成失败或契约校验未通过
- **THEN** 系统不登记该产物
- **AND** 详情中对应该分析版本显示不可用原因

#### Scenario: 历史补登记
- **WHEN** 既有没有流程图记录的分析版本被读取
- **THEN** 系统按 builtin 渲染器补生成并标注来源为「历史补登记」
- **AND** 登记后后续读取不再重复补登

#### Scenario: 原型登记
- **WHEN** 需求生成或修订原型
- **THEN** 每个原型版本出现在原型分类
- **AND** 展示页数与确认状态

#### Scenario: 说明书登记
- **WHEN** 生成需求说明书或迭代说明书
- **THEN** 对应版本出现在需求说明书分类
- **AND** 需求说明书标注生成技能 slug 与版本，旧版无技能字段的标注「旧版渲染」
- **AND** 迭代级说明书标注纳入需求数量

#### Scenario: 空流程排除
- **WHEN** 分析版本没有功能流程步骤
- **THEN** 系统不为该版本生成流程图产物
- **AND** 需求详情中仍显示流程空态

### Requirement: 产物预览
系统 SHALL 支持在不下载文件的情况下直接预览产物，预览内容自包含且不引用外部资源；流程图按渲染器形态预览，说明书按生成技能版本预览。

#### Scenario: 预览说明书
- **WHEN** 用户点击说明书产物的预览
- **THEN** 系统在浏览器中打开该版本的 HTML 说明书
- **AND** 目录、章节与图片与生成时一致
- **AND** 技能化版本页脚标注生成技能与版本

#### Scenario: 预览原型
- **WHEN** 用户点击原型产物的预览
- **THEN** 系统打开原型页面
- **AND** 多页原型提供页面切换

#### Scenario: 预览流程图
- **WHEN** 用户点击流程图产物的预览
- **THEN** 系统打开自包含 HTML 页面
- **AND** renderer=archify 时按流程步骤顺序展示可交互工作流图（内联 SVG、节点悬停可见、无脚本执行）
- **AND** renderer=builtin 时按步骤清单展示起点、动作、条件与终点
- **AND** 页面不请求外部脚本、样式、字体或图床

#### Scenario: 产物不可用
- **WHEN** 产物文件缺失、损坏或与生成记录不一致
- **THEN** 系统返回明确的不可用原因
- **AND** 不返回空白页、损坏文件或降级占位

#### Scenario: 访客预览
- **WHEN** 访客预览产物
- **THEN** 系统仅允许已发布说明书与已确认原型
- **AND** 拒绝草稿产物并说明原因
