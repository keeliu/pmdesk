# 变更提案：产物技能化（流程图走图表技能、说明书走组装技能）

## Why

1. **流程图不是技能产物**：当前流程图由服务端按 `analysis.functions.flow` 即时推导为步骤清单 HTML，不落库、不记录来源技能，prd-visuals（图表生成）与 archify（架构图）两个已绑定技能完全不参与，技能包覆盖率报告与实际产物脱节。
2. **需求说明书不走组装技能**：单需求说明书由固定九段渲染器确定性生成，未使用 prd-assemble（说明书组装）技能契约，章节结构（9 章）与该技能约定的五章正文 + 附录 A–Q 结构不一致，无法满足「最终说明书章节结构和内容遵守技能约定」的要求。
3. **可追溯性不完整**：迭代说明书已记录技能绑定、slug、版本与模板摘要，但流程图与需求说明书没有任何技能溯源字段，产物无法回答「由哪个技能、哪个版本、按什么模板生成」。

## What Changes

- **流程图技能化**：分析版本提交且包含功能流程步骤时，系统按图表技能解析链（项目绑定的 prd-visuals + archify → 内置技能包 → 确定性降级渲染并明示）生成流程图产物，持久化为自包含 HTML（可交互 SVG 工作流图），记录渲染器与技能溯源；需求详情、知识库、工作台对应功能提供预览。
- **需求说明书技能化**：单需求说明书生成改为经 prd-assemble 契约解析（与迭代说明书同一解析链），按技能约定的五章正文 + 附录 A–Q 结构组装，HTML 外壳遵循技能模板占位符契约；`specs` 表新增技能溯源字段，历史版本保持可查并按旧口径标注。
- **注册与预览打通**：流程图作为独立产物登记入知识库与需求详情过程文档，展示渲染器与技能版本；既有即时推导路径退役为降级渲染器。

## Impact

| 影响能力 | 变化类型 |
| --- | --- |
| requirement-analysis | MODIFIED —— 分析版本留存产出流程图产物 |
| specification-publishing | MODIFIED —— 说明书组装改为技能驱动、五章 + 附录结构；ADDED 技能化生成与追溯、章节契约 |
| ai-orchestration | ADDED —— 图表技能解析链；需求说明书复用既有文档技能解析链 |
| knowledge-base | MODIFIED —— 流程图按持久化产物登记与预览，展示技能元数据 |
| requirement-detail | MODIFIED —— 过程文档展示流程图与说明书的技能溯源 |

不影响：迭代说明书生成路径（已是技能驱动）、评审、变更、跟踪、规划、权限模型、状态机。
