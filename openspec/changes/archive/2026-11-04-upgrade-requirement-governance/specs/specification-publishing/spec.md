## ADDED Requirements

### Requirement: 迭代说明书组装
系统 SHALL 按迭代聚合全部纳入需求的分析内容，组装为迭代级需求分析说明书，包含迭代总览、需求分篇与附录三部分。

#### Scenario: 生成草稿版
- **WHEN** 产品经理在迭代详情发起生成说明书
- **THEN** 系统纳入迭代内状态不为待澄清、已丢弃的需求
- **AND** 组装迭代总览、需求分篇与附录
- **AND** 缺失内容在对应章节标注待补

#### Scenario: 生成正式版
- **WHEN** 全部纳入需求均具备分析版本、一致性核查通过、原型已确认且说明书已发布
- **THEN** 系统生成正式版本并标注版本号与生成时间
- **AND** 每个章节标注来源需求编号与更新时间

#### Scenario: 正式版缺项
- **WHEN** 任一纳入需求缺少分析版本、未通过一致性核查、原型未确认或说明书未发布
- **THEN** 系统拒绝生成正式版
- **AND** 输出缺项清单并允许生成草稿版

#### Scenario: 需求内容更新
- **WHEN** 迭代内某条需求产生新的分析或说明书版本
- **THEN** 既有迭代说明书标记为待更新
- **AND** 不自动合并，须重新生成

#### Scenario: 迭代为空
- **WHEN** 迭代内没有可纳入的需求
- **THEN** 系统拒绝生成说明书
- **AND** 提示先完成需求排期与确认

### Requirement: 迭代说明书在线预览
系统 SHALL 按 prd-pipeline 的 prd-assemble 交付契约生成单文件自包含 HTML，并在迭代详情内提供在线预览。

#### Scenario: 打开预览
- **WHEN** 用户点击在线预览
- **THEN** 系统在迭代详情内展示说明书 HTML
- **AND** 左侧目录可跳转到迭代总览、任一需求章节与附录

#### Scenario: 自包含资源
- **WHEN** 说明书包含流程图、架构图或原型截图
- **THEN** 图片以 base64 内嵌且不引用外部图床、CDN 或外部样式
- **AND** 断开网络后仍可完整阅读

#### Scenario: 锚点直达
- **WHEN** 用户通过链接打开某条需求章节
- **THEN** 页面定位到该需求的稳定锚点
- **AND** 目录同步高亮当前位置

#### Scenario: 缺图占位
- **WHEN** 某图表或原型截图缺失
- **THEN** 预览显示占位与原始说明
- **AND** 在附录的一致性核查中列出

### Requirement: 迭代说明书导出
系统 SHALL 支持将迭代说明书导出为 Word 与 PDF，导出内容与在线预览保持一致。

#### Scenario: 导出 Word
- **WHEN** 用户请求导出 Word
- **THEN** 系统基于同一份说明书源生成文件
- **AND** 文件名包含迭代名称与版本号
- **AND** 章节、图片与需求条目数量与 HTML 一致

#### Scenario: 导出 PDF
- **WHEN** 用户请求导出 PDF
- **THEN** 系统通过无头浏览器打印同一份 HTML 生成 PDF
- **AND** 内联图片、目录与章节结构与 HTML 一致

#### Scenario: PDF 引擎不可用
- **WHEN** 运行环境缺少可用的无头浏览器
- **THEN** 系统返回导出失败与原因
- **AND** 不生成降级或损坏的 PDF 文件

#### Scenario: 导出一致性校验失败
- **WHEN** 导出文件的章节数、图片数或需求条目数与 HTML 不一致
- **THEN** 系统标记导出失败并保留差异明细
- **AND** 不提供该文件下载

#### Scenario: 导出留痕
- **WHEN** 导出成功
- **THEN** 系统记录导出人、格式、迭代、版本与时间
- **AND** 记录关联的说明书版本

## MODIFIED Requirements

### Requirement: 说明书版本管理
系统 SHALL 为单需求说明书与迭代说明书分别维护版本序列，记录每版变更摘要、触发来源与审批状态，并保留需求版本与迭代版本之间的引用关系。

#### Scenario: 生成新版本
- **WHEN** 分析、原型或评审导致内容变化
- **THEN** 系统生成新版本并关联触发来源
- **AND** 旧版本转为只读

#### Scenario: 版本发布标记
- **WHEN** 某版本通过评审
- **THEN** 系统将其标记为已发布版本
- **AND** 后续导出默认使用该版本

#### Scenario: 迭代版本引用需求版本
- **WHEN** 迭代说明书生成成功
- **THEN** 系统记录其引用的每条需求说明书版本
- **AND** 可按需求版本追溯其参与过的迭代说明书

#### Scenario: 需求版本更新后的迭代版本
- **WHEN** 已关联需求的说明书发布新版本
- **THEN** 引用旧版本的迭代说明书标记为待更新
- **AND** 旧迭代版本保持可查
