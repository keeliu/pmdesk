## MODIFIED Requirements

### Requirement: 迭代说明书组装
系统 SHALL 按迭代聚合全部纳入需求的分析内容，使用项目登记且适用于「说明书」环节的技能，组装为迭代级需求分析说明书，并在生成时同时固化 HTML 与 Word 两份产物。

#### Scenario: 生成草稿版
- **WHEN** 产品经理在迭代详情发起生成说明书
- **THEN** 系统纳入迭代内状态不为待澄清、已丢弃的需求
- **AND** 组装迭代总览、需求分篇与附录
- **AND** 缺失内容在对应章节标注待补

#### Scenario: 生成正式版
- **WHEN** 全部纳入需求均具备分析版本、一致性核查通过、原型已确认且说明书已发布
- **THEN** 系统生成正式版本并标注版本号与生成时间
- **AND** 每个章节标注来源需求编号与更新时间

#### Scenario: 正式版缺项
- **WHEN** 任一纳入需求缺少分析版本、未通过一致性核查、原型未确认或说明书未发布
- **THEN** 系统拒绝生成正式版
- **AND** 输出缺项清单并允许生成草稿版

#### Scenario: 需求内容更新
- **WHEN** 迭代内某条需求产生新的分析或说明书版本
- **THEN** 既有迭代说明书标记为待更新
- **AND** 不自动合并，须重新生成

#### Scenario: 迭代为空
- **WHEN** 迭代内没有可纳入的需求
- **THEN** 系统拒绝生成说明书
- **AND** 提示先完成需求排期与确认

#### Scenario: 使用技能生成
- **WHEN** 用户确认生成说明书并选择了一个可用文档技能
- **THEN** 系统按该技能的 HTML 模板与校验规则组装文档
- **AND** 版本记录技能绑定、技能 slug、技能版本与模板摘要
- **AND** 文档页脚与附录标注生成技能与版本

#### Scenario: 没有可用文档技能
- **WHEN** 项目没有启用且适用「说明书」环节的技能
- **THEN** 系统拒绝生成并说明原因
- **AND** 提示在技能管理中启用或添加文档技能

#### Scenario: 同时固化双产物
- **WHEN** 说明书生成成功
- **THEN** 系统同时保存 HTML 与 Word
- **AND** 记录 Word 文件名、大小与 SHA-256
- **AND** Word 的章节数与纳入需求数一致

#### Scenario: 产物生成失败
- **WHEN** HTML 校验、Word 生成或文件写入任一环节失败
- **THEN** 系统不创建说明书版本
- **AND** 清理已写入的临时文件并返回失败原因

#### Scenario: 重新生成沿用技能
- **WHEN** 用户基于既有版本重新生成且上一版本技能仍可用
- **THEN** 系统默认使用上一版本技能
- **AND** 若上一版本技能不可用，要求重新选择

#### Scenario: 历史版本兼容
- **WHEN** 历史说明书版本没有技能记录或 Word 文件
- **THEN** 历史版本仍可预览与导出
- **AND** 列表显示未记录技能
- **AND** Word 按内置技能与标准结构即时生成


### Requirement: 迭代说明书在线预览
系统 SHALL 把迭代说明书以单文件自包含 HTML 的形式提供，并在新标签页直接打开该 HTML 文件，而不是在应用内嵌 iframe 预览。

#### Scenario: 打开预览
- **WHEN** 用户点击迭代说明书的预览入口
- **THEN** 浏览器在新标签页打开该版本的 HTML
- **AND** 左侧目录可跳转到迭代总览、任一需求章节与附录

#### Scenario: 预览响应
- **WHEN** 浏览器请求预览地址
- **THEN** 响应以 `Content-Disposition: inline` 返回 HTML
- **AND** 禁止缓存并声明 `nosniff`
- **AND** 不允许被应用页面或第三方页面以 iframe 嵌入

#### Scenario: 自包含资源
- **WHEN** 说明书包含流程图、架构图或原型截图
- **THEN** 图片以 base64 内嵌且不引用外部图床、CDN 或外部样式
- **AND** 断开网络后仍可完整阅读

#### Scenario: 锚点直达
- **WHEN** 用户通过链接打开某条需求章节
- **THEN** 页面定位到该需求的稳定锚点
- **AND** 目录同步高亮当前位置

#### Scenario: 缺图占位
- **WHEN** 某图表或原型截图缺失
- **THEN** 预览显示占位与原始说明
- **AND** 在附录的一致性核查中列出

#### Scenario: 预览权限
- **WHEN** 访客请求草稿版本的预览地址
- **THEN** 系统拒绝访问
- **AND** 已发布版本按既有权限规则可查看

#### Scenario: 脚本与外部请求被阻断
- **WHEN** 预览 HTML 被浏览器加载
- **THEN** 响应安全策略禁止脚本执行与外部资源请求
- **AND** 只允许内联样式与 data 图片


### Requirement: 迭代说明书导出
系统 SHALL 支持将迭代说明书导出为 Word 与 PDF；Word 优先返回生成时固化的文件，导出内容与在线预览保持一致。

#### Scenario: 导出 Word
- **WHEN** 用户请求导出 Word
- **THEN** 系统返回该版本生成时固化的 Word 文件
- **AND** 文件名包含迭代名称与版本号
- **AND** 章节、图片与需求条目数量与 HTML 一致

#### Scenario: 固化文件缺失
- **WHEN** 新版本记录的 Word 文件不存在或大小不符
- **THEN** 系统返回产物缺失错误
- **AND** 不静默重新生成或返回其它版本的文件

#### Scenario: 历史版本导出
- **WHEN** 历史版本没有固化的 Word 文件
- **THEN** 系统按内置技能与标准结构即时生成 Word
- **AND** 不回写历史版本记录
- **AND** 在导出审计中标注为回退生成

#### Scenario: 导出 PDF
- **WHEN** 用户请求导出 PDF
- **THEN** 系统通过无头浏览器打印该版本存储的 HTML 生成 PDF
- **AND** 内联图片、目录与章节结构与 HTML 一致

#### Scenario: PDF 引擎不可用
- **WHEN** 运行环境缺少可用的无头浏览器
- **THEN** 系统返回导出失败与原因
- **AND** 不生成降级或损坏的 PDF 文件

#### Scenario: 导出一致性校验失败
- **WHEN** 导出文件的章节数、图片数或需求条目数与 HTML 不一致
- **THEN** 系统标记导出失败并保留差异明细
- **AND** 不提供该文件下载

#### Scenario: 导出留痕
- **WHEN** 导出成功
- **THEN** 系统记录导出人、格式、迭代、版本与时间
- **AND** 记录关联的说明书版本、技能 slug 与技能版本
